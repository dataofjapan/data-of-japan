# データソース

「参議院選挙で、どれだけの人が投票したか」のデータソース調査と、データ層の設計方針。
調査日: 2026-09-26。URL と表の中身は取得して確認済み。

## 1. 結論

一次情報源は総務省の次の3つ。

| 用途 | 資料 | 範囲 |
| --- | --- | --- |
| 全国（時代） | [第26回確定結果調](https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040269606&fileKind=2)（e-Stat、PDF）の13–15ページ「当日有権者数、投票者数」「男女別投票率」 | 第1〜26回 |
| 全国（第27回）・都道府県 | 各回の結果ページの「都道府県別有権者数、投票者数、投票率（選挙区）」「同（比例代表）」 | 第19〜27回 |
| 年代 | 「[国政選挙の年代別投票率の推移について](https://www.soumu.go.jp/senkyo/senkyo_s/news/sonota/nendaibetu/index.html)」の「[参議院議員通常選挙における年代別投票率（抽出）の推移](https://www.soumu.go.jp/main_content/000646811.pdf)」 | 第15〜27回 |

- 全国は第1回（1947年）から。参議院の通常選挙はすべて男女普通選挙。
- 第12回までは、全国を1つの選挙区とする全国区と、都道府県ごとの地方区。第13回（1983年）から比例代表と選挙区。配信データでは全国区を比例代表（`pr`）、地方区を選挙区（`sd`）の列に置き、画面で呼び方を分ける。
- 都道府県別は、兄弟サイト（得票・候補者）と同じ第19回から。形式は第19回が HTML、第20回が PDF、第21回以降が Excel。
- 年代別は抽出調査（§4）。

出典表記: 総務省「参議院議員通常選挙結果調」、総務省「国政選挙の年代別投票率の推移について」。

### 確定と速報

確定結果調に載っている第1〜26回を「確定」、確定結果が公表されていない第27回を「速報」とする。

## 3. 読み方の決まり

- 投票率 = 投票者数 ÷ 選挙当日の有権者数。
- 確定結果調の「当日有権者数、投票者数」は、回ごとに 全国区（比例代表）・第n回・地方区（選挙区）の3行。有権者数は、第2〜18回は両区分に共通で「第n回」の行に1つだけ、第1回と第19回からは区分ごとの行にある。
- 第1回の地方区の有権者数は、無投票選挙区を除いた数（括弧書き。表の注記）。
- 同じ冊子の「男女別投票率」（男・女・計）は、上の人数から小数第2位で四捨五入した値と第1〜26回のすべての行で一致する（読むたびに確かめる）。
- 都道府県別の表の行は、都道府県 + 9つの数（有権者・投票者・棄権者 × 男・女・計）。全国の行は「計」か「合計」。
- 第24回からの選挙区の表には、合区（鳥取県・島根県、徳島県・高知県）が「（再掲）」として付く。2県の和と一致することを確かめて読み飛ばす。
- Excel は先頭のシートだけを読む。2枚目のシートは「うち在外」（在外選挙人の内数）で、先頭のシートの数に含まれている。
- 第19回の HTML は、9つの数の右に投票率・前回の投票率・比較の欄が続く。投票率が整数（51.00 など）だと人数と見分けられないので、先頭の10列（都道府県 + 9つの数）だけを読む。
- 表の中の「計」（男 + 女）と「棄権者」（有権者 − 投票者）は読むたびに突き合わせ、合わなければ止める。
- 第20回の PDF は `pdftotext -layout`（poppler）で読む。この表には空欄がないので、行の数値を左から順に取る。

## 4. 年代別投票率（抽出調査）

「参議院議員通常選挙における年代別投票率（抽出）の推移」の下の表（10歳代〜70歳代以上・全体 × 第15〜27回）を読む。総務省は通常選挙のたびに同じ URL の PDF を差し替える。

- 全数の集計ではない。表の注記「この表のうち、年代別の投票率は、全国の投票区から、回ごとに142〜188投票区を抽出し調査したものです」。
- 表の注記: 第24回の10歳代の投票率は全数調査の値。
- 10歳代は第24回（選挙権年齢が18歳以上になった回）から。値は右詰めで、欠けているのは古い回。
- 上のグラフにも同じ数字と年代の名前が散らばっているので、表の見出し（最後の「回」の行）より下だけを読む。
- 「全体」の行は抽出でなく全国の投票率。第15〜27回のどの回も、確定結果調・結果ページの表から計算した全国の選挙区の投票率と一致する（`npm run verify`）。

## 5. 突き合わせ（`npm run verify`）

- 確定結果調: 目録の第1〜26回がそろう。
- 都道府県別: 都道府県の和 = 全国の行（選挙区・比例代表、第19〜27回）。
- 確定結果調との照合: 第19〜26回の結果ページの全国の行 = 確定結果調（§2 の既知の差を除く）。投票率は一致。
- 年代別: 第15〜27回がそろう。10歳代は第24回から。「全体」= 全国の選挙区の投票率。

## 6. 配信データ

`npm run data` が `data/normalized/*.json` だけを入力に、`public/data/` に書き出す。

| ファイル | 次元 | 値 |
| --- | --- | --- |
| `era.json` | 制度（選挙区・比例代表）× 回（第1〜27回） | 男女別の有権者数・投票者数（全国） |
| `pref.json` | 制度 × 回（第19〜27回）× 都道府県 | 男女別の有権者数・投票者数 |
| `age.json` | 年代 × 回（第15〜27回） | 投票率（百分率、表のまま）と全体 |

## 7. 配色

`src/lib/data/palette.ts`。兄弟サイトでは色相を党に使う。このサイトに党は出ないので、男女計は無彩色（墨）、男女は兄弟サイトの性別の内訳と同じ Okabe–Ito の2色（男性 空色・女性 朱色）。
地図の明度は投票率の関数。目盛りは2つから選ぶ。

- この回の範囲（既定）: 選んだ回・制度・男女の都道府県の最低〜最高を、外側の整数の%に丸めたもの。
- 全回共通: 第19回からの全回・全都道府県・男女の投票率（37.9〜72.3%）が収まる 35〜75%。どの回でも同じ明るさが同じ投票率になる。
