# データソース

「参議院選挙で、どの党がどれだけ票を得てきたか」のデータソース調査と、データ層の設計方針。
調査日: 2026-09-26。URL と表の中身は取得して確認済み。

## 1. 結論

一次情報源は総務省「参議院議員通常選挙結果調」（政府統計コード `00200236`）。
各回の結果ページ（[一覧](https://www.soumu.go.jp/senkyo/senkyo_s/data/sangiin/ichiran.html)）にある次の4表を使う。

| id | 表 | 用途 |
| --- | --- | --- |
| `sdPref` | 都道府県別党派別得票数（選挙区） | 都道府県・全国（「計」の行） |
| `prPref` | 都道府県別党派別得票数（比例代表） | 都道府県・全国（「計」の行） |
| `sdNational` | 党派別得票数（選挙区） | 全国値の突合 |
| `prNational` | 党派別得票数（比例代表） | 全国値の突合 |

範囲は第19回（2001年）から。比例代表が非拘束名簿式（党名と候補者名のどちらでも投票できる）になった最初の回で、党の得票の意味がここで変わる。
結果ページは第19回から総務省サイトにある（一覧ページに載るのは第21回から）。

| 回 | 形式 |
| --- | --- |
| 19 | HTML（Shift_JIS） |
| 20 | PDF |
| 21〜26 | xls |
| 27 | xlsx |

出典表記: 総務省「参議院議員通常選挙結果調」。

### 確定と速報

総務省の各回のページはどれも「速報結果」の見出しで公開されている。確定結果調は e-Stat にある（第21〜26回。[第26回](https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040269606&fileKind=2) は467ページ）。
第26回確定結果調の「通常選挙における党派別得票数の推移」（pp.24–26）には第1〜26回の全国の党派別得票がある。
第19〜26回の全国の総得票と自由民主党の得票を、この推移表の値と `npm run verify` で突き合わせ、一致を確認した。このため第19〜26回を「確定」とし、確定結果が公表されていない第27回を「速報」とする。
第27回のページにある「参結果調全体版」（[001034533.pdf](https://www.soumu.go.jp/main_content/001034533.pdf)、99ページ）は結果ページの表をまとめたもので、確定結果調ではない。

## 3. 読み方の決まり

- 党名は各回の届出名称のまま。全角英数は半角に寄せ、空白と注記（※1）を除く。2行に折られた党名はつなぐ。衆議院のシリーズと同じ決まりなので、同じ党は同じ文字列になる。
- 別の回の同名・後継の党はつながない（第23回と第25回以降の日本維新の会、第25回と第26回以降の立憲民主党・国民民主党）。党名が同じ文字列の場合だけ同じ系列になる。
- 空欄・ダッシュ・0 は「その都道府県に候補がない」として欠損。
- 按分票があるので小数第3位まで残す。
- 有効投票数は各表の「合計」列（選挙区）・「合計」の組（比例代表）。得票率は得票数 ÷ 有効投票数。
- 選挙区の表は党ごとに 男・女・計 の3列。党の列は小見出しの位置から決め、党名はその上の見出しをつなげて読む。見出しは、数値のある行（前の組の県・計・再掲）の手前まで遡る。
- 第24回からの合区（鳥取県・島根県、徳島県・高知県）は、選挙区の表で県ごとの行のほかに「（再掲）」として計の下に付く。県ごとの行だけを読む。
- 比例代表の表は党ごとに 得票総数・得票率・政党等の得票総数・名簿登載者の得票総数 の4列。得票総数（小見出し「得票率」の左の列）だけを読む。
- 見出しだけ残った使われない組は、値が入っていなければ読み飛ばす。値があれば止める。
- 第19回の HTML は表（`<table>`）ごとに SheetJS で読み、Excel と同じ行にしてから同じ解析器に通す。全国表のセルは「得票数」と「(得票率)」が改行で並ぶので1行目を読む。
- 第20回の PDF は `pdftotext -layout`（poppler）で読む。選挙区の表は空欄が詰まるので、数値の右端の位置を小見出しの位置と照らして列を決める。比例代表の表は空欄がないので、数を左から4つずつ党に当てる。第20回は全国表を読まない（都道府県表の「計」を全国値とし、確定値と突き合わせる）。

## 4. 突き合わせ（`npm run verify`）

- 都道府県ごと・全国で、党の和 = 合計。得票はどれも正。
- 47都道府県がそろう。都道府県の和 = 全国（党ごと・合計）。
- 全国表の「今回」= 都道府県表の「計」（党の顔ぶれと値）。第20回を除く。
- 確定値: 第19〜26回の全国の総得票と自由民主党の得票（§2）。

## 5. 配信データ

`npm run data` が `data/normalized/*.json` と `data/shugiin-palette.json` だけを入力に、`public/data/` に書き出す。

| ファイル | 次元 | 値 |
| --- | --- | --- |
| `era.json` | 制度 × 回 × 党 | 得票数（全国）・有効投票数 |
| `sd-pref.json` | 回 × 都道府県 × 党 | 得票数（選挙区）・有効投票数 |
| `pr-pref.json` | 回 × 都道府県 × 党 | 得票数（比例代表）・有効投票数 |
| `palette.json` | 党 | 色相 |

### 党の色

衆議院のシリーズに出た党は、[election-shugiin-timeseries](https://github.com/visualizing-jp/election-shugiin-timeseries) が全国の得票から決めた色相（`public/data/palette.json`）をそのまま使う。`data/shugiin-palette.json` はその写し。
参議院にだけ出た党は、同じ規則（同じ回に出た主要な党どうしの色相をできるだけ離す）で、固定した色相を避けて割り当てる。
兄弟サイトの配色が変わったら写し直して `npm run data` を通す。
