# データソース

正本。パースや指標の定義はここを先に直す。

## 調べていること

日本人が海外へ出た回数と、戻ってきた人がどれだけ外にいたか。行き先の国は出国統計にない。目的と州は観光庁の別の調査で、出国回数の内訳にしない。

## 1. 出国（1964–2025）

- 日本政府観光局（JNTO）の年次表にある出国日本人数。同じ PDF に訪日外客数もあるが、このサイトでは使わない
- ページ: https://www.jnto.go.jp/statistics/data/visitors-statistics/
- 実数は出入国在留管理庁の出入国管理統計。1964–2025年は確定値
- `scripts/jnto.json` に転記してある。PDF のファイル名は更新のたびに変わるので、取り直すときはページの年次 PDF から出国の列だけを更新する
- 出国日本人数は出国した回数

## 2. 誰が出国し、どれだけ外にいたか（2006–2025）

出入国管理統計（e-Stat 統計コード `00250011`）の年次ファイル。年 → `statInfId` は `scripts/catalog.json`。`npm run fetch` が落とす。

| ファイル | 表 | 軸 |
| --- | --- | --- |
| `who-{年}.xlsx` | 住所地別 年齢（5歳階級）・性別 出国日本人 | 住所地 × 年齢 × 男女 |
| `stay-{年}.xlsx` | 滞在期間別 年齢（5歳階級）・性別 帰国日本人 | 滞在期間 × 年齢 × 男女 |

- 住所地は旅券を取得した場所。居住地ではない。「外国」は海外で旅券を取った人
- 全国の出国（男女計）は、同じ年の JNTO 出国日本人数と一致する
- 滞在期間の区分は重ならない。「10日以内」は「5日以内」の次の区分で、合計が帰国の総数になる
- 帰国の総数と出国の総数は近いが同じではない。戻ってきた人の数と、出ていった回数

## 3. 目的と州（2014–2025）

- 観光庁「旅行・観光消費動向調査」の年次集計表（確報）
- ページ: https://www.mlit.go.jp/kankocho/siryou/toukei/shouhidoukou.html
- 第4表の海外旅行。年合計のブロックだけ使い、四半期は捨てる
- 目的は観光・レクリエーション、帰省・知人訪問、出張・業務。行き先は州（アジア、ヨーロッパ、北アメリカ、南アメリカ、アフリカ、大洋州）
- 表は千人単位。人に戻すとき四捨五入する。内訳の合計が計と 1千人ぶんずれる年がある
- 2025年の海外旅行の計は、同じ年の帰国日本人の総数と一致する。標本を帰国の数に広げた推計で、出国回数を目的別に割ったものではない

## 配信チャンク

| ファイル | 内容 |
| --- | --- |
| `era.json` | 年 → 出国回数（1964–） |
| `who.json` | 住所地 × 性 × 年齢 × 年（2006–）→ 出国 |
| `stay.json` | 滞在期間 × 性 × 年齢 × 年（2006–）→ 帰国 |
| `purpose.json` | 州 × 目的 × 年（2014–）→ 延べ旅行者数 |
| `meta.json` | 年一覧・出典 |

## 検証（`npm run verify`）

- 1964年の出国 127,749、2025年の出国 14,731,615
- 各年: 出国の全国 = JNTO、住所地の合計 = 全国、年齢の合計 = 全国
- 各年: 滞在期間の合計 = 帰国の総数
- 各年: 目的の合計 ≈ 計（差は 2,000人以内）
- 2025年: 観光庁の海外旅行の計 = 帰国の総数

## 範囲外

- 国別の到着数（JNTO が各国統計を転記したもの。定義が国ごとに違い、合計しても出国にならない）
- 在留邦人（3か月以上の人数）。姉妹サイト「日本人は海外のどこに住んできたか」
