# データソース

「日本はどれだけ人を刑務所に入れてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-11。軸は犯罪白書 Excel の実測値で確認済み。

## 1. 結論

刑事施設にいる人・入った人・外で見る人を、**時代・入所・保護**の3ビューで見せる。
一次ソースは法務省「令和7年版 犯罪白書」の累年 Excel。原統計は矯正統計年報（`00250005`）と保護統計年報。

矯正年報の e-Stat データベース表は単年表が中心で、長期比較には向かない。第1版は白書 Excel のみ。e-Stat API / SSDS は使わない。少年院・鑑別所は `juvenile`。

| ビュー | 一次ソース | 表 | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 犯罪白書 | `2-4-2-1` / `2-4-2-2` / `shiryo2-5` / `5-3-1` / `2-5-2-1` / `2-4-2-4` | 指標×年 | 年末収容・入所・収容率・再入・仮釈放 |
| 入所 | 犯罪白書 | `2-4-2-4` + `2-4-2-5`（2024スナップショット） | 年齢×年 | 人員・構成比。罪名は単年 |
| 保護 | 犯罪白書 | `shiryo2-9` | 指標×年 | 仮釈放・執行猶予保護観察・保護観察率 |

出典表記: 法務省「犯罪白書」。原統計は矯正統計年報・保護統計年報。

## 2. 採用データセット（メタ・実測）

### `2-4-2-1.xlsx` — 刑事施設の年末収容人員・人口比（1946–2024）

- 出典: [令和7年版 犯罪白書 第2編第4章第2節](https://hakusyo1.moj.go.jp/jp/72/nfm/n72_2_2_4_2_0.html)
- 年末収容は受刑者のほか、未決の被告人・被疑者などを含む
- 実測:
  - **1949年 96,609**（戦後のピーク。人口10万人当たり 118.1）
  - **2006年 81,255**（平成のピーク）
  - **2024年 40,544**（人口比 32.7）。女性 3,671（9.1%）
  - 2024年の受刑者（一部執行猶予＋なし）33,745

### `2-4-2-2.xlsx` — 入所受刑者の人員・人口比（1946–2024）

- フロー。ストックの年末収容とは別系列
- 実測（2024年）: **14,822**（女性比 10.5%）
- 2006年: 33,032

### `shiryo2-5.xlsx` — 収容率（1972–2024）

- 収容人員÷収容定員。100%超は定員オーバー
- 実測: **2002年 106.5%**（ピーク）/ 2006年 102.4% / **2024年 49.9%**
- 女性の収容率は2001年から。第1版の時代指標は総数

### `5-3-1.xlsx` — 再入者率（1989–2024）

- 入所受刑者のうち、過去にも受刑した人の割合
- 実測: 1989年 62.3% / 2006年 50.0%（16,528 / 33,032）/ **2024年 53.7%**（7,957 / 14,822）

### `2-5-2-1.xlsx` — 仮釈放率（1949–2024）

- 出所受刑者のうち仮釈放で出た人。S24–H27 と H28–R6（総数）を接続
- 実測（2024年）: 満期釈放等 5,592 / 仮釈放 9,448 / **仮釈放率 62.8%**

### `2-4-2-4.xlsx` — 入所受刑者の年齢層（1971–2024）

- 図①男・図②女。第1版は男女合算
- 60代の 60–64 / 65–69 内訳は1984年から
- 実測（2024年、合算 14,822）: 20歳未満 27 / 20代 2,620 / 30代 2,949 / 40代 3,143 / 50代 3,052 / 60代 1,661 / 70歳以上 1,370
- 高齢者比（65歳以上、合算）**13.8%**。白書の「高齢者率」は男女別（男 12.9% / 女 21.6%）

### `2-4-2-5.xlsx` — 入所罪名（2024年スナップショット）

- 長期の罪名別累年は第1版では持たない
- 実測（2024年）: 窃盗 5,418 / 覚醒剤取締法 2,987 / 詐欺 1,431

### `shiryo2-9.xlsx` — 保護観察開始人員（1949–2024）

- 3シートで列配置が違う（S24–S63 / H元–H27 / H28–R6）
- 少年は `juvenile` に残し、成人側（仮釈放＋執行猶予保護観察）を出す
- 実測（2024年）: 総数 23,978（少年含む）/ 仮釈放 9,448 / 全部及び一部執行猶予 2,169 / 全部執行猶予の保護観察率 **4.9%**
- 2016年以降の執行猶予側は一部執行猶予を含む。率は全部執行猶予のみ

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| e-Stat 矯正年報の単表 | 表番号が年次プレフィックス。長期に不足。`prosecution` と同じ判断 |
| 矯正施設別・庁別 | 地図の物語ではない。収容の全国長期が核 |
| 罪名の長期 | 白書 `2-4-2-5` は単年。年報累年は第2版 |
| 少年院・鑑別所 | `juvenile` |
| 婦人補導院 | 2024年終了。保護観察の注記に残す程度 |
| 白書 `2-5-3-1` | タイトルのみで数値表が空。`shiryo2-9` で代替 |

## 4. 接続・定義ルール

- **年末収容** = 各年末に刑事施設にいる人（未決を含む）
- **入所受刑者** = その年に刑の執行のため入所した人
- **収容率** = 年末収容人員 / 収容定員
- **再入者率** = 再入者 / 入所受刑者
- **仮釈放率** = 仮釈放 / （満期釈放等 + 仮釈放）
- **高齢者比** = （65–69 + 70歳以上）/ 入所受刑者。男女合算
- 表示年は西暦。欠測は `null`（収容率は1971年以前、再入は1988年以前）

## 5. 配信ファイル

`scripts/build_data.py` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | persons / rate | metrics |
| `age.json` | code × year | persons / share | codes, offenses |
| `probation.json` | metric × year | persons / rate | metrics |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。
`per_100k` だけは率ではなく人口10万人当たりの実数を `rate` メジャーに載せる。

## 6. 注記（UIに短く出す）

- 年末収容は受刑者だけではない
- 平成の過密（収容率100%超）のあと、収容は半分近くまで減った
- 減ったあとも再入者率は5割前後で下がっていない
- 入所の顔ぶれは若年が減り、高齢が増えた
- 少年の保護観察は別コンテンツ

## 7. 更新手順

API キーは不要。

1. `npm run fetch` で白書 Excel を `data/raw/hakusyo/` に置く
2. [犯罪白書](https://hakusyo1.moj.go.jp/jp/nendo_nfm.html) の URL は `scripts/fetch-xlsx.sh` が年版パス（`jp/72/`）を持っている。新年版では差し替える
3. `npm run data && npm run verify`
4. 年末収容・入所・仮釈放が白書の当該図と一致することを確認する

`ESTAT_APP_ID` は第2版で API を使うときまで不要。配信用 JSON は追跡する。
