# データソース

「日本人はどんな病気で病院にかかってきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。統計表IDは e-Stat の公開一覧（令和５年患者調査）から取得し、軸は `npm run meta` の実レスポンスで確認する。

## 1. 結論

**厚生労働省「患者調査」（政府統計コード `00450022`）が一次情報源。**
3年に1回の標本調査。ある一日の入院・外来推計患者数と、人口10万対の**受療率**を公表する。
「死因」（人口動態・全数）の姉妹編として、**生きている人がどんな傷病で医療を受けているか**を見る。

「疾病 × 年 × 性 × 年齢 × 地域」を単一表では持たない。軸ごとに表を分ける。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 全国編 受療率の年次推移×傷病 | `0004025892` | 入院–外来 × 傷病 × 年 | 受療率（人口10万対） |
| 時代（人数） | 全国編 推計患者数の年次推移×傷病 | `0004025886` | 同上 | 推計患者数（千人） |
| 疾病 | 全国編 性・年齢×傷病 | `0004025899` | 性 × 年齢 × 傷病 × 施設 | 推計患者数 |
| 地域 | 都道府県編 受療率×傷病 | `0004026105` | 入院–外来 × 傷病 × 都道府県 | 受療率（人口10万対） |

第1版の時代軸は **平成8年～令和5年**（`0004025892` / `0004025886`）に限定する。
昭和54年～平成5年表（`0004025891` / `0004025885`）は ICD 体系が大きく異なり、ラベル接続が不完全なため見送り。

出典表記: 厚生労働省「患者調査」（e-Stat）。

## 2. 採用データセット（一覧確認済み・メタは取得で確定）

令和５年患者調査（調査年月 2023、公開 2025-03-17）のデータベース表。

### 時代（傷病 × 年）— 第1版は平成8年以降

| statsDataId | 表 | 期間 |
| --- | --- | --- |
| `0004025892` | Z5-2 受療率の年次推移，入院－外来 × 傷病分類別 | 平成8年～令和5年（10時点） |
| `0004025886` | Z3-2 推計患者数の年次推移，入院－外来 × 傷病分類別 | 同上 |

- 調査は概ね3年ごと。連続年ではない。
- 傷病コードは表内の `01`–`60` を正準とする（ゼロ埋め）。

### 見送り: 昭和54年～平成5年

| statsDataId | 表 | 理由 |
| --- | --- | --- |
| `0004025891` / `0004025885` | Z5-1 / Z3-1 | ICD 体系が現行と大きく異なり、章の対応が不完全 |

### 疾病（年齢プロファイル・最新調査年）

| statsDataId | 表 |
| --- | --- |
| `0004025899` | Z9 推計患者数，性・年齢階級（５歳） × 傷病分類 × 病院－一般診療所別 |

- 年次軸はなく、令和5年時点の断面。入院–外来の区別はない（施設種類のみ）。
- 病院・一般診療所の再掲があるため、施設は**総数**を採用。
- 年齢の「65歳以上（再掲）」等は除外し、5歳階級のみ。

### 地域

| statsDataId | 表 |
| --- | --- |
| `0004026105` | T37 受療率（人口10万対），入院－外来・施設の種類 × 傷病分類 × 都道府県別 |

- 入院（総数）・外来（総数）のみ採用（病院／診療所の内訳は再掲）。
- メタの都道府県コード `1`–`48` を `00000` / `01000`–`47000` に正規化。

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| Z5-1 / Z3-1（昭和54–平成5） | ICD 断絶。章ラベルの機械接続が不完全 |
| Z4 / Z2（年齢×年次推移） | 傷病横断の年齢は疾病ビューの断面で足りる |
| 傷病中分類・小分類の巨大表（Z13–Z16 等） | セル数が大きく、第1版の物語に必須ではない |
| 総患者数（T62 等） | 受療率のほうが人口規模を除ける |
| 二次医療圏・流入流出（T1–T3） | スコープ外 |

## 4. 定義・接続ルール

- **受療率** = 推計患者数 / 人口 × 100,000（公表値をそのまま使う。自前再計算しない）
- **入院 / 外来** を切替の主軸にする（時代・地域）。疾病ビューは表に入院–外来が無いため施設総数×性
- 時代の傷病コードは Z5-2 の体系に揃える。疾病・地域表の数字コードはゼロ埋めで同一キーにする
- 地域の相対指標: `県の受療率 / 全国の受療率`（全国=1）
- 推計患者数の単位は表の表章に従う（千人表示の場合はビルドで実人数に直さない。メタの単位を確認）

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | setting × disease × year | rate, patients | diseases, settings |
| `disease.json` | setting × disease × sex × age | patients | diseases, ages |
| `geo.json` | setting × disease × area | rate, relative | diseases, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 患者調査は3年に1回の標本調査。ある調査日の推計であり、年間罹患の全数ではない
- 受療率は人口10万対。高齢化の影響を含む（年齢調整受療率は第1版では出さない）
- 「死因」ダッシュボードとは統計が別。死亡原因と受療傷病は一致しない
- ICD 改訂により傷病分類の長期比較は完全一致しない

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```
