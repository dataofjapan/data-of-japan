# データソース

「日本ではどんな犯罪が起きてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

刑法犯の**認知件数・検挙率・罪種構成**を、**時代・罪種・地域**の3ビューで見せる。
一次ソースは総務省「社会・人口統計体系」（都道府県データ）の分野 **Ｋ　安全**。
原統計は警察庁「犯罪統計」（政府統計コード `00130001`）。SSDS はそれを都道府県・年次に整理した系列。

警察庁「犯罪統計」の e-Stat データベース表は、API 上は 2016 年次の単年表のみ（例: `0003191340`）。
戦後〜直近の長期比較には向かないため、第1版は SSDS の長期系列（1975–2024）を採用する。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | SSDS 基礎データ + 社会生活統計指標 | `0000010111` + `0000010211` | 指標×年 | 認知・検挙・検挙率・人口当たり |
| 罪種 | 同上（基礎データ） | `0000010111` | 罪種×年 | 認知件数・構成比・検挙率 |
| 地域 | 同上 | `0000010111` + `0000010211` | 指標×年×都道府県 | 人口当たり認知・検挙率 |

出典表記: 警察庁「犯罪統計」（社会・人口統計体系経由・e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0000010111` — 都道府県データ 基礎データ Ｋ　安全

- 軸: 観測値(1) × Ｋ安全(170) × 地域(48) × 調査年(50: 1975–2024)
- 採用コード（犯罪）:
  - 認知: `K4201`（刑法犯）/ `K420101` 凶悪 / `K420102` 粗暴 / `K420103` 窃盗 / `K420104` 知能 / `K420105` 風俗
  - 検挙件数: `K4202` および同細分 `K420201`–`K420205`
  - 検挙人員: `K4203` / 少年 `K4204`
  - 特別法: `K4301` / 覚醒剤 `K4303`
- 年次コードは `YYYY100000`（ラベルは「YYYY年度」。犯罪統計の暦年値を SSDS が収録）
- 実測（全国）: 1975年 刑法犯認知 1,234,307件 / 2002年 2,853,739件

### `0000010211` — 都道府県データ 社会生活統計指標 Ｋ　安全

- 軸: 同上形状、指標コード 58
- 採用:
  - `#K06101` 刑法犯認知件数（人口千人当たり）
  - `#K06104` 窃盗犯認知件数（人口千人当たり）
  - `#K06201` 刑法犯検挙率（％）
  - `#K06204` 窃盗犯検挙率（％）
  - `#K06401` / `#K06402` / `#K06403` / `#K06405` 罪種別構成比（％）
  - `#K06501` 特別法犯検挙件数（人口10万人当たり）
- 実測（全国）: 2002年 刑法犯検挙率 20.8%

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 警察庁「犯罪統計」API 単年表（`0003191xxx`） | 2016年のみ。長期・罪種・地域の物語に不足 |
| 市区町村 SSDS（`0000020111` 等） | 第1版は都道府県で十分。セル数が大きい |
| 手口別窃盗・重要犯罪の詳細 | 罪種（刑法犯6区分）で物語が足りる |
| 1945–1974 の戦後直後 | SSDS に無い。警察白書の紙・PDF からの手起こしは第2版 |
| 知能犯の構成比指標 `#K06404` | 指標表に欠落。基礎データの件数比で算出 |

## 4. 接続・定義ルール

- **刑法犯**は警察庁犯罪統計の定義（道路上の交通事故による致死傷等を除く、など）。詳細は警察庁の利用上の注意に従う
- 罪種構成の「その他」= `K4201 − (凶悪+粗暴+窃盗+知能+風俗)`。残差として扱う
- 検挙率は原則 SSDS 指標 `#K06201` / `#K06204`。罪種別は件数から `検挙件数/認知件数`
- 地域の相対色は**全国比**（人口千人当たり認知・検挙率）
- 表示年は暦年ラベル（SSDS の調査年コードの西暦部分）

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | cases / rate / share | metrics |
| `type.json` | code × year | cases / share / clearance | codes |
| `geo.json` | metric × year × area | value / relative | metrics, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 認知件数は警察が認知した刑法犯。暗数（未認知）は含まない
- 2002年前後は認知のピークと検挙率の低下が重なる
- 窃盗が件数の大半を占める。構成比の変化は窃盗の増減に強く依存する
- SSDS の収録は 1975年以降。それ以前は第1版の対象外

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```
