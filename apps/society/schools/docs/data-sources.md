# データソース

「日本人はどんな学校に通ってきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-06。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

高校卒業後の進路（大学・短大・専修・就職など）と、高等教育の在学者構成の長期変化を、**時代・学校種・男女**の3ビューで見せる。
単位は**人数**とその構成比。進学率（％）は姉妹テーマ `japan-data-education` の担当で、ここでは扱わない。

一次ソースは文部科学省「学校基本調査」。長期の横断接続は社会・人口統計体系「Ｅ　教育」（学校基本調査由来）を使う。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 社会・人口統計体系 基礎データ Ｅ教育 | `0000010105` | 進路×全国×年 | 人数・構成比（分母=高校卒業者） |
| 学校種 | 同上 | `0000010105` | 学校種×全国×年 | 在学者数・構成比（高等教育内） |
| 男女 | 同上 | `0000010105` | 学校種×性×年 | 在学者数・女性割合 |

出典表記: 文部科学省「学校基本調査」（社会・人口統計体系経由含む、e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0000010105` — 都道府県データ 基礎データ「Ｅ　教育」

- 軸: 観測値(1) × Ｅ教育(494) × 地域(48) × 調査年(50: 1975–2024年度)
- 学校基本調査などの公表値を横断接続した指標群
- 調査年コードは `YYYY100000`（「YYYY年度」）

#### 時代ビュー — 高等学校卒業者の進路（件数）

| コード | 内容 | 備考 |
| --- | --- | --- |
| `E4601` | 高等学校卒業者数 | 構成比の分母 |
| `E460101` / `E460102` | 同上（男／女） | 参考 |
| `E4602` | 進学者数（大学・短大） | 検証用。`E460210`+`E460220` と近接 |
| `E460210` | 短期大学進学者数 | 男女分割コードはメタに無し |
| `E460220` | 大学進学者数 | 同上 |
| `E4603` | 専修学校等入学者数 | 男 `E460301` / 女 `E460302` |
| `E4604` | 就職者数 | 男 `E460401` / 女 `E460402` |
| `E4605` | 家事手伝い・外国の大学・進路未定等 | 男 `E460501` / 女 `E460502` |

進路構成比 = 各進路人数 / `E4601`。進学率（education）ではなく、卒業者の行き先のミックスを見せる。

#### 学校種ビュー — 在学者数

| コード | 内容 | 構成比 |
| --- | --- | --- |
| `E4501` | 高等学校生徒数 | 分母外（参照用）。男 `E450101` / 女 `E450102` |
| `E6301` | 短期大学学生数 | 高等教育分母に含む。男 `E630101` / 女 `E630102` |
| `E6302` | 大学学生数 | 同上。男 `E630201` / 女 `E630202` |
| `E7201` | 専修学校生徒数 | 同上。男女分割はメタに無し |
| `E7202` | 各種学校生徒数 | 同上 |

高等教育の構成比分母 = 短大 + 大学 + 専修 + 各種。

#### 男女ビュー

在学者の男女がある学校種（高校・短大・大学）について、計・男・女の在学者数と、計セルの女性割合（女/計）を配信する。

## 3. 姉妹テーマとの役割分担

| | `japan-data-education` | `japan-data-schools`（本リポ） |
| --- | --- | --- |
| 問い | どこまで学ぶようになったか | どんな学校に通ってきたか |
| 主な指標 | 進学率（％） | 進路・在学者の人数と構成比 |
| 学校種 | 義務教育〜大学の在学者全体 | 高等教育経路に寄せた在学者 |
| 第3ビュー | 進学率の男女差 | 在学者の男女構成 |

## 4. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 大学／短大進学者の男女分割 | SSDS メタに `E460210`/`E460220` の性別コードが無い |
| 高等専門学校の在学者数 | 「Ｅ教育」に対応コードが見当たらなかった（費用指標 `E8110` のみ） |
| 都道府県別進路マップ | 第1版は全国の物語に集中。地域は将来拡張 |
| 学校基本調査の年次別「卒業後の状況」原表 | 年次で表IDが分かれ長期接続コストが高い。SSDS で足りる |
| 進学率指標（`E4701` 等） | education と重複するため採用しない |

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | path × year | count, share | paths |
| `school.json` | school × year | enrollment, share | schools |
| `gender.json` | school × sex × year | enrollment, female_share | schools, sexes |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。
構成比は 0–1 の割合（表示は％）。

## 6. 注記（UIに短く出す）

- 進学率ではなく、高校卒業者の進路構成と在学者構成を扱う
- 大学・短大進学者の男女内訳は SSDS に無い。男女ビューは在学者ストック
- 進路構成比の分母は高校卒業者。進路カテゴリ合計が100%にならない年があり得る（定義・集計の差）
- 学校種の構成比は高等教育（短大・大学・専修・各種）内。高校は人数のみ

## 7. 更新手順

```
npm run meta

npm run data
npm run verify
```
