# データソース

「日本はどれだけごみを出してきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-06。軸・コードは e-Stat API のメタ（社会・人口統計体系「Ｈ　居住」）で確認済み。

## 1. 結論

一般廃棄物の**排出量・1人1日当たり・リサイクル・最終処分**を、**時代 / 処理 / 地域**の3ビューで見せる。
一次ソースの骨格は、社会・人口統計体系（都道府県データ）の「Ｈ　居住」生活環境系。
原統計は環境省「一般廃棄物処理事業実態調査」（政府統計コード `00650101`）。
環境省調査の e-Stat はファイル提供が中心で、API 長期時系列の都道府県横断には向かないため、第1版は SSDS の接続系列を採用する。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | SSDS 基礎データ + 社会生活統計指標 | `0000010108` + `0000010208` | 指標×年 | 排出・原単位・リサイクル・最終処分 |
| 処理 | 同上（基礎データ） | `0000010108` | フロー区分×年 | 排出内訳・資源化・最終処分 |
| 地域 | 同上 | `0000010108` + `0000010208` | 指標×年×都道府県 | 原単位・リサイクル率・埋立率 |

出典表記: 環境省「一般廃棄物処理事業実態調査」（社会・人口統計体系経由・e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0000010108` — 都道府県データ 基礎データ Ｈ　居住

- 軸: 観測値(1) × Ｈ居住(多数) × 地域(48) × 調査年(51: 1975–)
- ごみ関連は生活環境ブロック（`H56xx`）。住宅指標と同表
- 調査年コードは `YYYY100000`（ラベルは「YYYY年度」。原統計は年度）
- 採用コード（排出・処理）:
  - `H5609` ごみ総排出量（総量・t）
  - `H560901` 計画収集量 / `H560902` 直接搬入量 / `H560903` 自家処理量 / `H560904` 集団回収量
  - `H5610` 1人1日当たりの排出量（g/人日）
  - `H5612` ごみ処理量（総量） / `H561201` 直接資源化
  - `H5613` 中間処理後再生利用量
  - `H5614` ごみのリサイクル率（％）
  - `H5615` ごみ最終処分量（t）
  - `H5616` 最終処分場埋立容量 / `H5617` 最終処分場残余容量
- 実測（全国）:
  - `H5609` / `H5614` / `H5615`: 1999–2023 年度（25年）
  - `H5610` / 排出内訳 / `H561201` / `H5613`: 2005–2023 年度（19年）
  - 2023: 総排出 38,974,270 t / 1人1日当たり 851 g / リサイクル率 19.5% / 最終処分 3,156,322 t
  - 2005: 1人1日当たり 1,131 g

### `0000010208` — 都道府県データ 社会生活統計指標 Ｈ　居住

- 軸: 同上形状
- 採用:
  - `#H055031` ごみのリサイクル率（％）
  - `#H055041` ごみ埋立率（％）
  - `#H05505` 最終処分場残余容量

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 環境省調査の API/ファイル単年表（`00650101`） | 長期×都道府県の物語に不足。ファイル中心で API 一覧も空だった |
| 焼却処理量（トン） | SSDS「Ｈ　居住」に焼却トンの専用コードが無い。処理ビューは資源化・最終処分で代替 |
| 市区町村 SSDS | 第1版は都道府県で十分 |
| 産業廃棄物 | テーマは一般廃棄物 |
| し尿処理（`H55xx`） | ごみ物語から外す |

## 4. 接続・定義ルール

- **総排出量** = `H5609`（計画収集＋直接搬入＋自家処理＋集団回収の関係は調査定義に従う）
- **1人1日当たり** = `H5610`（g/人日）。％ではない
- **リサイクル率** = 原則基礎 `H5614`。指標表 `#H055031` は地域ビューの率系バックアップ／整合確認用
- **埋立率** = `#H055041`（最終処分の人口規模に依存しない比較用）
- **処理ビューの構成比**:
  - 排出内訳: 各内訳 ÷ `H5609`
  - 資源化・処分: `H561201` / `H5613` / `H5615` は総排出または処理総量を分母にせず、**総排出 `H5609` に対する比**として並べる（物語の軸を排出に固定）
- 地域の相対色は**全国比**（原単位・率）
- 表示年は年度ラベル（調査年コードの西暦部分）

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | tonnes / intensity / rate | metrics |
| `flow.json` | code × year | tonnes / share | codes |
| `geo.json` | metric × year × area | value / relative | metrics, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 一般廃棄物（市町村等が処理）。産業廃棄物は含まない
- 年度。表示の「年」は調査年度の西暦
- 焼却トンは SSDS に無いため第1版では扱わない
- 1人1日当たりとリサイクル率の相関は弱く、地域差は別軸で読む
- SSDS 収録開始前の年は欠測

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```
