# データソース

「日本では非行少年をどう処遇してきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-11。軸は犯罪白書 Excel の実測値で確認済み。

## 1. 結論

少年院に入った人・鑑別所にいた人・出たあとの行き先を、**時代・入所・処遇**の3ビューで見せる。
一次ソースは法務省「令和7年版 犯罪白書」の累年 Excel。原統計は少年矯正統計年報（`00250006`）。

年報の e-Stat データベース表は単年表が中心で、長期比較には向かない。第1版は白書 Excel のみ。e-Stat API / SSDS は使わない。警察の少年検挙は `crime`。刑事施設は `prisons`。

| ビュー | 一次ソース | 表 | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 犯罪白書 | `3-2-4-1` / `3-2-3-2` / `3-2-3-4` | 指標×年 | 入院・一日平均在院・鑑別所・少年院送致・女子比 |
| 入所 | 犯罪白書 | `3-2-4-2` + `3-2-4-3`（2024スナップショット） | 年齢×年 | 人員・構成比。非行名は単年 |
| 処遇 | 犯罪白書 | `3-2-3-4` | 退所事由×年 | 人員・構成比 |

出典表記: 法務省「犯罪白書」。原統計は少年矯正統計年報。

## 2. 採用データセット（メタ・実測）

### `3-2-4-1.xlsx` — 少年院入院者・一日平均在院人員（1949–2024）

- 出典: [令和7年版 犯罪白書 第3編第2章第4節](https://hakusyo1.moj.go.jp/jp/72/nfm/n72_2_3_2_4_0.html)
- 新たに少年院送致となった人。3シートを接続
- 実測:
  - **1951年 11,333**（戦後のピーク）
  - **2000年 6,052**（平成のピーク）
  - **2022年 1,332**（底）
  - **2024年 1,828**（男 1,670 / 女 158。女子比 8.6%）

### `3-2-3-2.xlsx` — 少年鑑別所の被収容者（1982–2024）

- 出典: [令和7年版 犯罪白書 第3編第2章第3節](https://hakusyo1.moj.go.jp/jp/72/nfm/n72_2_3_2_3_0.html)
- 観護措置などで入り、その年に移送・逃走・死亡以外で退所した人。男女別シートを合算
- 実測（2024年）: 男 5,036 + 女 538 = **5,574**

### `3-2-3-4.xlsx` — 少年鑑別所退所者の退所事由（1975–2024）

- 保護観察・児童自立/養護施設・少年院送致・検察官送致・審判不開始/不処分・観護措置の取消し・試験観察・その他
- 実測（2024年、総数 6,851）:
  - 保護観察 **2,231**
  - 少年院送致 **1,828**（入院系列と一致）
  - 試験観察 608
  - 観護措置の取消し 558

### `3-2-4-2.xlsx` — 少年院入院者の年齢（1968–2024）

- 入院時。18歳以上には入院時に20歳の人を含む
- 実測（2024年）: 16歳未満 260 / 16・17歳 749 / 18歳以上 819

### `3-2-4-3.xlsx` — 入院非行名（2024年スナップショット）

- 長期の非行名別累年は第1版では持たない
- 第5種を除く総数 1,826
- 実測（2024年）: 窃盗 411 / 傷害 376 / 詐欺 180 / 強盗 134

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| `3-2-3-1.xlsx` / `3-2-5-1.xlsx` | 図のみで数値表が空 |
| `shiryo3-1` | 警察の少年検挙。`crime` の領域 |
| `3-2-4-10` 矯正教育課程 | コード表のみ。核にしない |
| e-Stat 少年矯正年報の単表 | 表番号が年次プレフィックス。長期に不足 |
| 施設別 | 地図の物語ではない。全国の長期が核 |

## 4. 接続・定義ルール

- **少年院入院** = 新たに少年院送致となった人（白書の「少年院入院者」）
- **一日平均在院** = その年の少年院在院の平均
- **鑑別所の被収容者** = 退所ベース。男女合算。1982年から
- **鑑別所から少年院へ** = 退所事由の少年院送致。入院とほぼ重なる。1975年から
- **女子比** = 女子入院 / 入院総数
- 表示年は西暦。欠測は `null`

## 5. 配信ファイル

`scripts/build_data.py` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | persons / rate | metrics |
| `age.json` | code × year | persons / share | codes, offenses |
| `disposition.json` | code × year | persons / share | codes |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 戦後すぐの入院ピークのあと、平成でも一度膨らみ、その後は最小を更新した
- 2023年以降、減少が止まった
- 鑑別所を出た人の行き先は保護観察が最も多い
- 少年院送致の人員は入院の系列とほぼ重なる
- 警察の少年検挙は crime の領域

## 7. 更新手順

API キーは不要。

1. `npm run fetch` で白書 Excel を `data/raw/hakusyo/` に置く
2. [犯罪白書](https://hakusyo1.moj.go.jp/jp/nendo_nfm.html) の URL は `scripts/fetch-xlsx.sh` が年版パス（`jp/72/`）を持っている。新年版では差し替える
3. `npm run data && npm run verify`
4. 入院・鑑別所・退所事由が白書の当該図と一致することを確認する

`ESTAT_APP_ID` は第2版で API を使うときまで不要。配信用 JSON は追跡する。
