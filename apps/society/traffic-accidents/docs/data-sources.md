# データソース

「日本人は交通事故でどれだけ傷ついてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

道路交通事故による発生件数・死者・負傷者を、**時代・被害・地域**の3ビューで見せる。
一次ソースは警察庁「道路の交通に関する統計」（政府統計コード `00130002`）。
長期件数は e-Stat DB の発生状況推移表、2019年以降と都道府県は社会・人口統計体系（Ｋ安全）で延長・補完する。

物語の核は、モータリゼーション期の急増（死者は1970年前後がピーク）から、その後の長期減少。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代（〜2018） | 交通事故の発生状況 推移 | `0003281500` | 指標×年 | 発生・死者・負傷・重傷・人口比 |
| 時代（2019〜） | 社会・人口統計体系 Ｋ安全 | `0000010111` / `0000010211` | 指標×全国×年 | 発生・死者・負傷・人口比 |
| 被害（状態） | 状態別死傷／負傷 | `0003287753` / `0003281503` | 状態×年 | 人数・構成比 |
| 被害（年齢） | 年齢層別死者／負傷 | `0003281495` / `0003281502` | 年齢×年 | 人数・構成比 |
| 地域 | 社会・人口統計体系 Ｋ安全 | `0000010111` / `0000010211` | 指標×都道府県×年 | 件数・人口比・全国比 |

出典表記: 警察庁「道路の交通に関する統計」（社会・人口統計体系経由含む、e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0003281500` — 交通事故発生状況の推移（1948–2018）

- 軸: 表章(7) × 年(71: 1948–2018)
- 採用表章: `1010` 発生件数 / `1080` 死者数 / `1190` 負傷者数 / `1250` 重傷者数 / `1470`・`1480` 人口10万人当たり
- 年次コードは `YYYY000000`
- 実測: 1970年 死者 16,765人 / 2018年 発生 430,601件・死者 3,532人・負傷 525,846人
- e-Stat DB はこの表群が 2020-10 更新のまま止まっており、2019年以降は別経路で延長

### `0000010111` / `0000010211` — 社会・人口統計体系 Ｋ安全

- 基礎: `K3101` 発生件数 / `K3103` 死者数 / `K3104` 負傷者数
- 率: `#K04101` 発生（人口10万人当たり）/ `#K04106` 死者 / `#K04107` 負傷
- 軸: 全国+47都道府県 × 調査年(1975–2024)。コードは `YYYY100000`（「YYYY年度」ラベルだが、突合上は暦年の警察庁値と一致）
- 実測突合: 2018年 発生・死者・負傷は `0003281500` と一致。2019年 発生 381,237 / 2024年 死者 2,663

### 被害（状態・年齢）

| 表ID | 内容 | 年 |
| --- | --- | --- |
| `0003287753` | 状態別死傷者（死者は `死傷者種別=120`） | 2005–2018 |
| `0003281503` | 状態別負傷者 | 2005–2018 |
| `0003281495` | 年齢層別死者 | 2005–2018 |
| `0003281502` | 年齢層別負傷者 | 2005–2018 |

- 状態の採用: 自動車 / 自動二輪 / 原付 / 自転車 / 歩行 / その他（計・二輪計は除外）
- 年齢の採用: 4歳以下〜85歳以上の細分（全年齢層・再掲は除外）
- 実測: 2018年 歩行中死者 1,258人

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 月報・月次 DB | 年次のモータリゼーション物語が主。季節性は第2版 |
| 30日以内死者 | 国際比較向き。第1版は24時間死者（本統計の主系列） |
| 都道府県別 NPA 表 `0003281571` | 2015–2018のみ。SSDS の方が長い |
| 事故類型・法令違反の詳細 | 第1版の3ビューに必須ではない |
| 年次ファイル（2024年報 CSV）からの被害延長 | API 外の手作業接続が増える。被害は2005–2018で確定し、延長は blocker として残す |

## 4. 接続・定義ルール

- **死者**は交通事故発生から24時間以内の死者（警察庁の主系列）
- 時代の件数: 1948–2018 は `0003281500`、2019–2024 は SSDS。2018年で突合一致を確認済み
- 発生件数の人口比は NPA 長期表に無いため SSDS（1975–）のみ
- 重傷者数は NPA 長期表のみ（〜2018）。以降は `null`
- 地域の相対色は **県値 / 全国値**（件数・人口比とも）
- 被害の構成比は各切り口の「計」を分母

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | people, rate | metrics |
| `harm.json` | dim × code × year | people, share | formDims, codes |
| `geo.json` | metric × year × area | value, relative | metrics, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 対象は道路上の人身事故（物損のみは含まない）
- 死者は原則24時間以内。30日以内死者とは定義が異なる
- 時代の2019年以降は社会・人口統計体系経由の警察庁値
- 被害（状態・年齢）の e-Stat DB は2018年まで

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く（コミットしない）。配信用 JSON は追跡する。
