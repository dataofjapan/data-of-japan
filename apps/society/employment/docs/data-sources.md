# データソース

「日本人はどんな働き方をしてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸は e-Stat API のメタ取得で確認済み。

## 1. 結論

働き方の長期変化を、**時代 / 就業形態 / 属性**の3ビューで見せる。
一次ソースは総務省「労働力調査」基本集計（年平均・全国）。
正規・非正規は API 上の接続が 2013年〜。それ以前の長期時系列 Excel は第1版では採らない（API 表IDが無い）。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 労働力調査 基本集計 年平均 | `0002060049` | 就業状態×性×年齢「15歳以上」×年 | 労働力人口比率・就業率・完全失業率 |
| 時代（地位） | 同上 | `0002060046` | 従業上の地位×性×年（全産業） | 自営・家族・雇用者数と構成比 |
| 時代（雇用形態） | 同上 | `0003078065` | 雇用形態×性×年齢「15歳以上」×年 | 正規・非正規（2013年〜） |
| 就業形態 | `0002060046` + `0003078065` | 形態×性×年 | 人数・構成比 |
| 属性 | `0002060049` + `0003078065` | 年齢×性×年 | 就業率・失業率・非正規比率 |

出典表記: 総務省「労働力調査」（e-Stat 経由）。

## 2. 採用データセット（メタ実測）

### `0002060049` — 年齢階級別労働力人口比率，就業率及び完全失業率（1953年～）

- 統計名: 労働力調査 基本集計　全都道府県 全国 年次
- 軸: 表章項目(1: 率) × 産業(1: 全産業) × 性別(3) × 就業状態(3) × 年齢階級(30) × 地域(1) × 年次(73: 1953–2025)
- 就業状態コード: `01` 労働力人口（＝労働力人口比率） / `13` 就業（＝就業率） / `08` 完全失業者（＝完全失業率）
- 性別: `0` 総数 / `1` 男 / `2` 女
- 公表値は％。配信では ÷100 して小数にする。
- 実測: 労働力人口比率・完全失業率は 1953年〜、**就業率は 1968年〜**（それ以前は欠測 `*`）。

### `0002060046` — 農林業・非農林業，従業上の地位別就業者数（1953年～）

- 軸: 表章項目(1: 実数) × 産業(3) × 従業上の地位(17) × 性別(3) × 地域(1) × 年次(73)
- 採用は産業「全産業」(`000`)。単位は万人（小数あり）。
- 配信する地位（重複しない主系列）:
  - `01` 自営業主 / `06` 家族従業者 / `08` 雇用者
  - 参考合算 `16` 自営業主・家族従業者は時代の補助指標にのみ使う

### `0003078065` — 雇用形態，年齢階級別雇用者数（2013年～）

- 軸: 表章項目(1) × 産業分類(2) × 性別(3) × 雇用形態(11) × 年齢階級(29) × 地域(1) × 年次(13: 2013–2025)
- 採用は産業「全産業」(`00`)。
- 雇用形態:
  - `03` 正規の職員・従業員 / `10` 非正規の職員・従業員
  - 非正規内訳: `04` パート・アルバイト / `07` 派遣 / `11` 契約社員 / `12` 嘱託 / `09` その他
  - 分母: 正規・非正規の構成比は `02` 役員を除く雇用者。内訳比は `10` 非正規。

### 年齢階級（属性ビュー）

重複しない5歳階級＋高齢者合算:

`15～19` `20～24` `25～29` `30～34` `35～39` `40～44` `45～49` `50～54` `55～59` `60～64` `65～69` `70～74` `75歳以上`

加えて合算行: `15歳以上` / `15～64歳` / `65歳以上`。

除外: `15～17` `18・19` `20・21` `22～24` など細分、および `40～54` のような重複合算。

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 長期時系列 Excel（表1-a-3 等、1984年～の正規・非正規） | ファイル提供のみ。API の statsDataId が無く、housing 系パイプラインと揃えない |
| `0003008332` 率（年齢なし・2000年～） | `0002060049` の年齢「15歳以上」で包含 |
| `0002060047` 就業状態の実数 | 率表と地位表で物語が足りる。第1版は件数を地位・雇用形態に限定 |
| `0002060048` 地位×年齢 | 属性は就業率・非正規比を優先。地位×年齢は拡張用 |
| 詳細集計の「非正規についた理由」 | 標本が小さく、第1版の問い（構造変化）から外れる |
| 地域別年平均 | 第1版スコープ外（全国の長期変化に集中） |

## 4. 指標・分母

- **就業率** = 就業者 / 15歳以上人口（公表定義）
- **完全失業率** = 完全失業者 / 労働力人口
- **労働力人口比率** = 労働力人口 / 15歳以上人口
- **地位の構成比** = 当該地位の就業者 / 就業者総数（`00`）
- **正規・非正規比** = 当該 / 役員を除く雇用者（`02`）
- 率は小数4桁、構成比も小数4桁に丸める。人数は万人のまま。

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × sex × year | value, workers | metrics |
| `status.json` | form × sex × year | workers, share | forms |
| `attrs.json` | age × sex × year | empRate, unempRate, lfpr, regular, nonregular, nonregularShare | ages |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 2011年: 東日本大震災による調査影響（岩手・宮城・福島の一部）。
- 正規・非正規の API 系列は 2013年〜。それ以前は長期時系列ファイルを参照。
- 人数は標本推計の万人単位。詳細集計の非正規理由とは接続しない。
- 「就業率」と「正規比率」は分母が異なる。

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く（コミットしない）。生レスポンスは `data/raw/`（gitignore）。配信用 JSON は追跡する。
