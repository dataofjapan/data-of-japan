# データソース

「日本人は何を食べてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸・件数は e-Stat API のメタ取得・実測で確認済み。

## 1. 結論

食生活の構造変化（米→小麦、魚→肉、乳製品・油脂の拡大）を、**時代・品目・供給（自給）**の3ビューで見せる。

一次ソースは農林水産省「食料需給表」（政府統計コード `00500300`）。
令和5年度確報（調査期間 `202304-202403`）の**項目別累年表**と**関連指標（自給率）**を採用する。
品目別累年表（穀類・肉類など個別表）は、供給純食料・熱量が項目別表に既に揃うため第1版では取得しない。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標・単位 |
| --- | --- | --- | --- | --- |
| 時代 | 項目別累年表 国民1人・1年当たり供給純食料 | `0004047565` | 品目×年度 | kg/人・年 |
| 時代（熱量） | 項目別累年表 国民1人・1日当たり供給熱量 | `0004047567` | 品目×年度 | kcal/人・日 |
| 品目 | 上記2表 | 同上 | 類別（L1）×年度 | kg、kcal、熱量構成比 |
| 供給 | 品目別自給率（重量ベース）／総合自給率等 | `0004047599` / `0004047600` | 指標×年度 | %（配信時は 0–1 の割合） |

出典表記: 農林水産省「食料需給表」（e-Stat）。

## 2. 採用データセット（メタ・実測）

いずれも `食料需給表 確報 令和５年度食料需給表`。年度軸は **1960年度〜2023年度**（64時点、コード `1001`–`1064`）。

### `0004047565` — 国民１人・１年当たり供給純食料

- 軸: 類別・品目別(65) × 年度(64)
- 軸の積: 4,160 / 実測取得 **4,156**（疎セルあり）
- 単位: kg/人・年（純食料）
- 「合計」行はない（熱量表のみ合計あり）
- 採用: 物語用の主要品目（米・小麦・肉類・魚介類・牛乳及び乳製品・油脂類など）と類別 L1

### `0004047567` — 国民１人・１日当たり供給熱量

- 軸: 類別・品目別(66) × 年度(64)
- 軸の積: 4,224 / 実測取得 **4,220**
- 単位: kcal/人・日
- `1066` = **合計**（構成比の分母）
- 品目ビューの構成比 = 品目熱量 / 合計熱量

### `0004047599` — 品目別自給率（重量ベース）の推移

- 軸: 品目(45) × 年度(64)
- 軸の積: 2,880 / 実測取得 **2,788**
- 単位: %（API値は百分率）
- **飼料自給率**付き行・参考行は第1版で除外（重量ベースの本系列のみ）

### `0004047600` — 総合自給率等の推移

- 軸: 指標(7) × 年度(64)
- 軸の積・実測: **448**
- 採用: 穀物自給率、主食用穀物自給率、供給熱量ベース総合、生産額ベース総合、食料国産率（熱量・生産額）
- 見送り: 「（参考：酒類を含む…）」は注記のみ

### 実測スナップショット（2026-09-05 取得）

| 指標 | 1960 | 2023 |
| --- | ---: | ---: |
| 米 供給純食料 (kg) | 114.9 | 51.1 |
| 肉類 供給純食料 (kg) | 5.2 | 33.9 |
| 魚介類 供給純食料 (kg) | 27.8 | 21.4 |
| 穀類 熱量構成比 | 62.8% | 35.6% |
| 総合自給率（熱量） | 79% | 38% |
| 米自給率 / 小麦自給率 | — | 99% / 17% |

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 品目別累年表（穀類 `0004047570` 等） | 生産・輸入・在庫の詳細。純食料・熱量は項目別表で足りる |
| 供給粗食料表 | 純食料の方が「食べてきた」物語に近い |
| たんぱく質・脂質の項目別表 | 第1版は熱量＋重量に集中 |
| 国際比較表 | 試算・スコープ外 |
| 年度別（単年）表 | 累年表で長期接続済み |
| 過去年度刊行の同名表 | 最新確報に長期系列が載るため不要 |

## 4. 接続・分母ルール

- **純食料 (kg)** と **供給熱量 (kcal)** は別指標。kg 同士の単純合計は総摂取量ではない
- **熱量構成比**の分母は `0004047567` の「合計」
- L1 類別（穀類・肉類等）と L2 子品目を同時に足さない（二重計上）
- 自給率は公表の百分率を 0–1 に変換して配信
- 年度ラベルは「YYYY年度」→ 表示・URL では西暦年 `YYYY`

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | item × year | kg, kcal | items |
| `item.json` | item × year | kg, kcal, share | items（L1 類別） |
| `supply.json` | metric × year | rate | metrics |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 食料需給表は「供給」ベース。家計の摂取量調査とは接続しない
- 純食料は可食部ベース。粗食料・歩留りは第1版では出さない
- 自給率の飼料自給率系列は除外。肉・乳・卵は重量ベース本系列
- 令和5年度確報の最新年は 2023 年度（概算と確定の扱いは原表注記に従う）
